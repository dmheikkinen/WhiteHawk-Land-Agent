💻 How to Set API Keys

Copy the commands for your platform, paste into your terminal, then restart this app. Keys set this way are only visible to your own user account.

{% for tab_id, tab_label in [('ps','PowerShell (this session)'),('win','Windows (permanent)'),('mac','macOS / Linux')] %} {% endfor %}

Sets the key for the current PowerShell session only. You must re-run the app in the same window.

$env:OPENAI_API_KEY  = "sk-proj-..."
$env:SERPAPI_API_KEY = "your-serpapi-key"

# Then start the app in the SAME window:
python -m uvicorn server:app --port 5000

Find your OpenAI key at platform.openai.com/api-keys · SerpAPI key at serpapi.com/manage-api-key

Sets the key permanently for your Windows user account. Close and reopen your terminal, then restart the app.

setx OPENAI_API_KEY  "sk-proj-..."
setx SERPAPI_API_KEY "your-serpapi-key"

# Close this terminal, open a new one, then:
python -m uvicorn server:app --port 5000

⚠ setx does not affect the current terminal window — you must open a new one.

Add to your shell profile (~/.zshrc or ~/.bashrc) for a permanent setting, or export just for this session.

# One-time session:
export OPENAI_API_KEY="sk-proj-..."
export SERPAPI_API_KEY="your-serpapi-key"

# Then:
python -m uvicorn server:app --port 5000

# Permanent — add these two export lines to ~/.zshrc or ~/.bashrc
